# Mohammad Mohammadi Portfolio - Next.js

Converted from the original React/Vite portfolio to Next.js App Router + TypeScript.

## Features

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- i18next + react-i18next (English/Persian)
- next-themes (light/dark/system)
- RTL/LTR switching-
- EmailJS contact form
